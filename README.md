# DailyDiary 📱

**DailyDiary** is an Android application developed in Java, designed to help users build consistent habits, track daily activities, and monitor their personal progress over time.

## 🎯 Purpose

DailyDiary aims to make personal development more structured by bringing habit tracking and daily progress monitoring together in one application.

## ✨ Features

- **Habit Tracking** — Keep track of daily habits and routines.
- **Daily Progress** — Monitor personal progress over time.
- **Personal Productivity** — Support consistency and better daily routines.

## 🛠️ Tech Stack

- **Platform:** Android
- **Language:** Java

## 🚀 Getting Started

1. Clone this repository.
2. Open the project in Android Studio.
3. Allow Gradle to sync and resolve project dependencies.
4. Build and run the application on an Android device or emulator.
